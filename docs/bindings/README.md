# Layer 1 — bindings

One page per binding file in `pengu/`, generated by `pengu bind` from the C headers in `include/`.
A binding is a **1:1 C surface**: `declare`, `rune`, `omen`, `const` and `alias`, never a wrapper,
and it is never edited by hand. If you want to know the exact C signature, a constant's value or
which types exist, this is the reference.

Calling a binding directly is always possible and sometimes right — see
[Notes, decisions and traps](../NOTES.md) for when the wrapper deliberately does not cover
something. Page names match the binding file: `raymath.md` documents `pengu/raymath.d.pengu`.
