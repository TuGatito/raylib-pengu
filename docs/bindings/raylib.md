### `LIGHTGRAY`

> const Color

--- Basic colors (hand-maintained) ---------------------------------------
raylib.h defines these as `#define NAME CLITERAL(Color){ r, g, b, a }`,
which `pengu bind` cannot fold into a constant, so they are written out by
hand. They are *declaration* constants: codegen does not re-emit them and the
C compiler takes each value from raylib.h itself.
